# Change Log

## 2026-08-10 — Stub HDR RHI window for Qt < 6.4 (Ubuntu 22.04 CI)

### Question
Can CI just upgrade to a newer Qt? For the **fork**, yes. For an upstream PR,
**no as the only fix**: official `build-unix-native` still uses Ubuntu 22.04 apt
Qt **6.2.x**, so a hard `#error` / Qt 6.4-only build will keep failing there.

### Fix
- Replace `#error` in `HDRRenderingManager.h` with `HDR_WindowStub` when Qt < 6.4.
- Skip compiling `HDR_RhiVideoWindow*.cpp/.h` via qmake when Qt < 6.4.
- Real QRhi HDR path remains on Qt 6.4+ (Windows / newer CI images).
